# Юнит-тесты Stellar Burgers

Проект покрывает юнит-тестами класс `Burger`. В тестах используются моки и параметризация.

## Установка

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Для Windows активация окружения выполняется командой:

```bash
venv\Scripts\activate
```

## Запуск тестов

```bash
pytest
```

Покрытие класса `Burger` проверяется автоматически. Минимально допустимое покрытие — 100%.
